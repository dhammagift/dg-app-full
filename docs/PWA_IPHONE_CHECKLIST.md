# Проверка PWA на iPhone (без Apple-аккаунта)

Зачем: приложение на телефон пока не поставить (нет аккаунта), а PWA в Safari — это **тот же
веб-слой**, что поедет в приложении. Поэтому всё, что можно, проверяется здесь, и каждая строка ниже
имеет пару в машинных проверках (`ios-ui` в CI + job `build`), чтобы было видно: это особенность iOS
или сборки.

Установка: Safari → dhamma.gift → Поделиться → **На экран «Домой»** → открыть с иконки →
Настройки → Offline library → Download (дождаться «Library ready»).

## Обязательный функционал

| # | Что сделать | Что должно быть | Машинная пара |
|---|---|---|---|
| 1 | Поиск: `kacchapa` | результаты с dn22 и sn56.11, подсветка `kacchapā` | 4 запроса к локальной базе |
| 2 | Поиск на русском: `черепаха` | те же тексты | `search-russian` |
| 3 | Ридер: открыть dn22 из результатов | текст с переводами, режимы (`st`/`mt`/`ml`), перелистывание prev/next | text/nav/TOC-кейсы |
| 4 | **Словарь**: в ридере тапнуть по слову | попап со словарной статьёй; кнопки в попапе работают | код словаря + таблица режимов |
| 5 | **Мультитул**: Tools → line-by-line, listdiff, makelist, rr; Help → Abbr. | каждая страница своя (не поиск и не белый экран) | 5 страниц инструментов по маркеру |
| 6 | Настройки (шестерёнка/бургер → Settings) | шторка настроек, строка «Offline library», версия | страница настроек по маркеру |
| 7 | **ТТС**: в ридере кнопка озвучки | звук идёт, кнопка закрытия закрывает плеер | плагин: голоса + `speak` принят |
| 8 | **Облако/вход Google**: войти | открывается Safari с «Sign in with Google», после входа возврат в PWA и статус «вошли» | URL входа + контракт страницы возврата (6/6) |
| 9 | Ссылки: тапнуть внешнюю (Memo, Docs, Compare) | открывается Safari, не пустой экран внутри PWA | правила внешних ссылок (`dgIsExternalUrl`) |

## Что уже подтверждено владельцем (2026-09-17)

- Поиск, ридер, словарь — **работают** на живых айфонах.
- Загрузка библиотеки **встаёт при блокировке экрана** — поэтому в веб-слой добавлен Screen Wake
  Lock (проверить: начать загрузку, не трогать телефон, экран не должен погаснуть).

## Что в PWA проверить нельзя (только в приложении)

- приём «поделиться» из других приложений;
- шорткаты по долгому нажатию на иконку;
- фоновая докачка (свернул приложение — передача идёт);
- озвучка через `AVSpeechSynthesizer` (в Safari своя, в WebView её нет).

Эти четыре — то, ради чего вообще собирается приложение; в PWA их нет по определению.
