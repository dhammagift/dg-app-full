# Handoff: заставки, экраны «нет соединения», слой приложения Uposatha

Для ИИ/разработчика, который внедряет. Дата: 2026-09-26.

## Файлы
- `App screens (standalone).html` — самодостаточный макет (открыть в браузере): заставки Dhamma.Gift / Dict / Uposatha и экраны ошибок, светлая+тёмная, ru+en.
- `source/App screens.html` — исходник того же макета (CSS/JS читаемые; все тайминги и тексты — в нём).
- `source/assets/` — знаки: `dg-full.png` (полный знак Dhamma.Gift — только он для заставок и ошибок; раковина — компактный вариант, сюда не идёт), `dict-mark.svg` (тёмная тема, прод), `dict-mark-light.svg` (светлая).
- `source/uposatha-app/app-refresh.css|js` — слой режима `?app=1` для dhamma.gift/uposatha-calendar: вкладки M3, переходы, рябь, герой «луна + отсчёт», заставка. Подключать после `uposatha-calendar.css/js`; активен только под `body.app`.

## Движение (общее)
- Кривая `cubic-bezier(.05,.7,.1,1)`, сборка знака ≤1,1 с, уход 300 мс (opacity 1→0, scale 1→1.04). В приложении — один проход, без повтора.
- Dhamma.Gift: цельный знак проявляется круговой маской от книги вверх + подъём 8 px, scale .96→1; затем блик. Без размытия. В светлой теме знак НЕ инвертировать и не затемнять — только тонкий абрис (drop-shadow ~0.5px).
- Dict: крюк → точка падает с отскоком → лестница растёт от точки → бирюзовая черта.
- Uposatha: луна поднимается из-под маски облака, штрихи облака прорисовываются с шагом 120 мс.
- Размеры знаков (одинаковые визуально): Dhamma.Gift 190×110, Dict 130×116, Uposatha 118×94.
- `prefers-reduced-motion` — статичный знак.

## Экраны «нет соединения»
Одна раскладка: знак (собирается как на заставке, один раз) → название → фраза → кнопка «Повторить»/«Try again», шаг 100 мс после знака.
Состояния: (1) нет сети при первом запуске — плюс строка «Повторим сами, когда сеть появится», повтор по событию `online`; (2) сайт не отвечает — сеть есть, старт не пришёл за 10 с или 5xx; (3) повтор — кнопка неактивна, со спиннером. Uposatha — доп. строка: «Напоминания уже стоят на телефоне и придут без сети.» Тексты ru/en — объект `T` в исходнике.

## Android
SplashScreen API (12+) показывает анимацию значка ≤1000 мс — в неё укладывается только знак; название показывать на первом кадре WebView. Для AVD Dhamma.Gift нужен векторный контур знака (сейчас только PNG).
